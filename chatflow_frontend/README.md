# ChatFlow React Frontend

React + Vite frontend for the learning-oriented chat/notification system.

## Run
npm install
npm run dev

## Build
npm run build

Included:
- Login
- Signup
- Home / conversation list
- 1:1 chat
- Group chat
- Notifications
- Settings
- Responsive layout

The UI currently uses local React state and mock data. It is ready to connect to REST APIs and WebSockets later.
